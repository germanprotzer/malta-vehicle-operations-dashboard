# malta-vehicle-operations-dashboard

Excel dashboard built with public vehicle data from Malta.

The goal of this project was to transform official vehicle statistics into a clear business dashboard focused on market structure, energy distribution, and recent registration activity.

Overview

This dashboard shows:

Total licensed vehicles in Malta
Main vehicle categories by stock size
Vehicle distribution by energy type
Top newly licensed vehicle categories in Q4 2025
Key business insights for market monitoring and operational planning
